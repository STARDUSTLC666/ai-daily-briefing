# AI 早报新闻规则（当前版）

## 1. 入选原则

- 不强制固定条数，默认最多 6 条；宁可少，也不把空新闻塞进成品。
- RSS、Google News、媒体源只做线索发现；最终稿必须回到原文、官网、官方博客、GitHub Release、Hugging Face / ModelScope、产品入口或可截图页面核对。
- 主流 AI 优先：OpenAI、Anthropic/Claude、Google/Gemini、DeepSeek、Qwen、Kimi、Mistral、Meta/Llama；国内补充看豆包、智谱、MiniMax、腾讯混元等。
- 一条新闻要能说清：发布/更新了什么、具体变化是什么、对用户或开发者有什么实际影响。

## 2. 官网爬取失败时的处理

- “没爬到信息”不等于“新闻信息少”。主流 AI 或明确大新闻必须先深挖。
- 自动尝试：渲染官网页面、点击“了解更多”、解析前端 JS/配置接口、抓官方博客/文档/API/模型页、保存截图和图片素材。
- 如果确认官网是 SPA 或配置接口驱动，优先写通用适配；仍抓不到的主流页面，再写专属 adapter。
- 深挖完成前，不允许把“信息不够”“官网抓取失败”“后面优化爬虫”写进成品。
- 最后仍拿不到具体事实的条目，不进成品。

### 2.1 官网源维护

- 官网首页不等于新闻源。产品首页、登录页、Pricing、Developers、Models 泛页、隐私政策、用户协议、招聘页、联系我们等只能作为辅助入口，不能直接进入成品。
- 能换成官方博客/新闻页就优先换源，例如 Qwen 官方博客、Kimi 官方博客、ByteDance Seed 官方站。
- 页面跳转到新域名时，要允许最终域名继续解析；例如 Llama 首页跳到 `developer.meta.com` 后，模型页仍算官方源。
- 链接文字只有“了解更多 / 技术博客 / 模型发布”时，允许从 URL slug 兜底提取具体模型名或版本号，例如 `glm-5.2`、`seedance-2-0`。
- 链接文字只有“此文档 / this documentation”这类蓝色泛链接时，不能只看链接文字；必须读取它所在的标题、日期和段落，把可点击链接背后的 `href` 与周围正文合并成一条新闻。
- 健康审计命令：

```powershell
py -3 scripts\audit_official_web_crawlers.py --source-timeout 75
```

审计必须同时看：

- 发现页是否能找到具体新闻/模型/发布页。
- 详情页是否能抓到正文、事实、图片或截图。
- 首条是否误入泛入口、政策页、价格页、招聘页。
- 失败源是否已有 RSS、GitHub、Hugging Face / ModelScope 等替代官方源；有替代源时可以不强行让官网首页产出新闻，但不能把泛页面塞进视频。

## 3. 发布门槛

必须至少命中一类具体信息：

- 模型/版本：模型名、版本号、参数、上下文、模态、权重、License。
- 产品/API：入口、价格、地区/权限、API、SDK、TokenHub、应用接入。
- GitHub Release：Version、What's New、Bug Fix、Breaking Change、升级建议。
- Benchmark：榜单名、分数、对比对象、测试口径。
- 用户/社区反馈：必须有源头截图，并说明测试条件，不能当官方结论。

### 3.1 X 官方人员动态

- X / Twitter 上经过识别的官方人员、项目成员、研究员动态，可以作为“X 官方人员动态”短讯进入早报。
- 这类内容不要求官网补证；如果没有官网源头，不要硬写“官网待确认”。
- 必须保留原帖截图，画面以弹窗/截图形式展示。
- 解说只说一句：谁在 X 上透露、暗示或确认了什么。
- 禁止把它写成正式发布、开放入口或发布时间。
- 如果后续出现官网、博客、文档或 Release，再合并为正式新闻。

以下不进成品：

- 标题只是“新闻 / News / Blog / 首页 / Research / Models / Docs / Pricing”。
- 只有“官网新闻页有更新”“页面更新”“信息不够”“了解更多”。
- 只有内部流程、筛选状态、爬虫状态、待优化说明。

## 4. 稿件风格

- 先写新闻稿，再生成视频和卡片。
- 直入主题：公司发布/更新了什么，改了什么，用户要怎么判断。
- 不平均分配时长：高价值 30 秒左右，普通新闻 10–20 秒，低价值快速带过或不入选。
- 禁止反复说：来源可查、后续继续观察、官方补证、等待更多消息、具体以官方为准。
- “待确认”只在必要时短说一次；有足够事实才播，事实不足则不播。
- 开发者建议要具体：例如“先在测试环境跑一次再升级”，不要说“关注是否影响”。

## 5. 卡片规则

- 卡片不是字幕，不能复读配音。
- 卡片标题不使用“ 一句话 ”，统一用“核心看点”等信息组件。
- 每张卡 2–3 秒能看懂；标题短，正文只放具体事实。
- 根据新闻类型动态组合组件，不固定四张。
- 最后一张可以是“编辑判断”，但不显示内部打分。

## 6. 成品拦截

成品校验会拦截这些可见文字：

- 一句话
- 信息不够
- 不能直接当成正式新闻
- 暂时剔除
- 爬虫 / 筛选 / 官网抓取
- 后面需要继续优化
- 是否影响
- 可以关注……是否……
